Leonida Trophy Guide — the best offline GTA 6 trophy guide and tracker: all 55 PlayStation 5 trophies with their official names, descriptions and grades, a cited guide in its own words for every trophy, a roadmap to the platinum, the one missable trophy flagged, a spoiler-free setting, filters by kind and grade, and progress that saves in the browser and can be exported and imported. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — it works fully offline, with no network requests at all.
